# App Access Instructions

Mukha requires an administrator account before the application can be used.

Google Play reviewers may use the following steps to access the application's functionality.

---

## Administrator Registration

1. Launch the application.
2. Select **Register**.
3. Create a new administrator account using a valid email address and password.
4. Sign in using the newly created account.

---

## Employee Registration

1. Open the **Employees** page.
2. Tap the **+** button in the top-right corner.
3. Enter the employee's information.
4. Complete the face enrollment process.
5. Save the employee.

---

## Attendance Verification

1. Navigate to the **Attendance** page.
2. Position the enrolled employee in front of the camera.
3. Wait for facial verification to complete.
4. The attendance record will be stored automatically.

---

## Attendance History

Attendance history can be viewed from the Attendance or Dashboard section of the application.

---

## Logout

Navigate to **Settings** and select **Log Out**.
