# Mukha

> Smart Face Recognition Attendance System

Mukha is an Android-based attendance management application that uses on-device AI and facial recognition technology to provide secure and efficient employee attendance verification.

Unlike traditional attendance systems, Mukha performs facial embedding generation directly on the user's device. Only encrypted facial embeddings required for verification are securely transmitted to the backend infrastructure for attendance management.

---

## Features

- 🔐 Secure Administrator Authentication
- 👥 Employee Management
- 😊 Face Enrollment
- ✅ Face Recognition Attendance
- 📊 Attendance History
- ⚡ On-device AI Inference
- ☁️ Firebase & MySQL Backend
- 🔒 Secure HTTPS Communication
